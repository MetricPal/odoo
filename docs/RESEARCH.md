# Research Protocol

For fast-changing or version-specific technical questions:

1. Prefer official primary sources.
2. Verify current version before implementation.
3. Record important findings.
4. Separate verified facts from assumptions.
5. Never silently use stale documentation.
6. For Odoo implementation, Odoo 20 Community source/documentation is authoritative. 
    - https://www.odoo.com/documentation/20.0/
    - https://www.odoo.com/documentation/master/developer/howtos.html
    - https://www.cybrosys.com/ 

Research output should be concise enough to be useful to the implementer and detailed enough to reproduce important decisions.
