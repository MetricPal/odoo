# Quality Bar

## Definition of Done

Research → Plan → Implement → Test → Review → Document → Report.

## Required checks

Depending on the task:
- unit tests
- integration tests
- Odoo module tests
- security/access tests
- UI tests
- static analysis/lint
- formatting
- build
- migration/upgrade checks
- performance checks
- documentation

## AI-specific quality

Validate:
- authorization boundaries
- prompt/tool injection resistance
- tool permission enforcement
- approval enforcement
- audit completeness
- hallucination/error handling
- deterministic fallback behavior

## Quality reporting

Each substantial task should report:
- what changed
- why
- tests run
- known limitations
- follow-up work
