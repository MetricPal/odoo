# 04 — Channel Detail

## HEADER

Show:
- Channel name
- Channel type
- Business purpose/team
- Company
- Active/Inactive
- Health/readiness

Show a concise runtime summary:
- Active outbound sender
- Number of inbound endpoints
- Connection status

## SECTIONS

### Outbound Senders
List configured senders and clearly mark exactly one active sender.

### Inbound Endpoints
List receiving endpoints and their purpose/status.

### Operations
Operational settings only.

### Alerts
Configuration and runtime warnings.

## TECHNICAL DETAILS

Technical implementation fields are secondary and expandable.

Never make raw runtime state the visual center of the channel record.
