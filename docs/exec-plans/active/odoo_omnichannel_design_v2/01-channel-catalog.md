# Channel catalog

Initial extensible catalog: WhatsApp Business, Telegram, Slack, Discord, LinkedIn, Facebook, Instagram, X, TikTok, YouTube, Threads and Pinterest.

Catalog entries are labels and intentional icons, not installed integrations. UI displays Not installed, Configuration required, Verified or Unavailable with a reason. Never show mock health as real connection health.

Messaging, social publishing, comments and reactions are separate operation families; a platform can support only a subset. See [capability matrix](06-capability-matrix.md) and [provider readiness](13-research-and-provider-readiness.md).

Email and SMS are excluded from new sending engines. Future activity bridges must reference native Odoo delivery records.
