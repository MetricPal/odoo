# Odoo 20 Research Skill

Before any Odoo-specific implementation:
1. Verify Odoo 20 Community source and official docs.
2. Identify exact APIs/models/views/assets involved.
3. Record findings in `docs/references/odoo20-verification.md`.
4. Flag uncertain assumptions.
5. Only then produce an implementation plan.

Never treat Odoo 18/19 snippets as authoritative for Odoo 20.
