# Project Skills

Skills should contain focused, reusable workflows rather than one giant instruction manual.

Each skill should have its own directory with `SKILL.md` and optional resources/scripts.

Recommended initial skills:
- odoo20-research
- odoo20-module-development
- ai-agent-development
- approval-governance
- flutter-mobile
- web-ux
- testing-and-verification
- documentation-gardening

Skills are expected to evolve as the project learns.
