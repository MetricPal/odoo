WhatsApp for Omnichannel

Connect an existing WhatsApp Business Cloud API account so your team can see incoming conversations in the shared Odoo inbox.

  • Receive private text messages from WhatsApp.
  • Control conversation access by team and company.
  • Send one short setup test to a confirmed tester.

Version 1 supports setup, incoming text and a test message. Normal business replies, templates and media are not implemented. Live Meta delivery has not been verified.
