# Project Gantt

Adds **Planned start** to tasks and a **Gantt** view (from the Gantt View module) to the task actions: bars run
from the planned start to the deadline, grouped by assignee, coloured by the task colour, with arrows for task
dependencies. Drag a bar to reschedule it or its right edge to move the deadline. A task with only a deadline shows
a one-day bar; a deadline before the planned start is refused.
