# Marketing: work management

The work behind campaigns, in the Marketing app (menu **Work**).

- **Tasks** (Project): the *Tasks* link under a campaign's name opens its tasks on a **Gantt chart** grouped by
  pillar (Awareness, Consideration, Conversion; Project Gantt module), with Kanban, List, Calendar and Activity
  views next to it; the project is created on first use (stages To do / In progress / Done). Each task has a
  pillar, a planned start and a deadline; dependencies show as arrows. Owners, due dates and planned hours are ordinary Project fields. Duplicates, repeats,
  templates and campaigns started from a template carry the task list; each task keeps its timing relative to
  the campaign start (field *Due (days before start)* on template tasks). Marketing users get Project access.
- **Requests**: what is needed, why, for whom, by when, budget and channels. Accept (or decline with a reason
  the requester sees), then **Start the campaign**: the request becomes the brief, optionally from a template.
- **Design**: the campaign's Execution tab shows its creatives (the latest version of each proof) as cards.
- **Proofs**: a creative and/or text for a campaign channel, sent to a reviewer other than its maker. The
  reviewer approves or requests changes (feedback required). **New version** keeps the old one; the *Compare*
  tab shows what changed (word diff) and both versions side by side. An approved proof fills the channel's
  draft. A campaign is not sent for review while one of its proofs is open.
- **Team workload**: per person, open campaign tasks (with planned hours and late ones), active campaigns they
  own and proofs waiting for their review.
- The control panel's *Your action needed* lists my tasks due within a week, proofs to review or fix, and new
  requests.
