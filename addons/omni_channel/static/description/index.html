Omnichannel

Governed communication for Odoo 20 Community

Configure communication teams and senders, prepare messages for approval, and review private-text conversations and inspect dispatch evidence in a native Odoo workspace.

Company and team boundaries apply throughout. Sender selection requires verified identity. Unknown outcomes require explicit reconciliation and never trigger an automatic resend.

Foundation release: outbound sending and inbound intake default to disabled; intake requires explicit policy activation and a verified provider integration. No production provider adapter is included.
